# XJNU 适配验证

适配文件为 `resources/XJNU/xjnu.js`。测试使用虚构课程、教师和教室，不包含学生账号、密码、登录会话或真实课表页面。

```sh
npm ci --prefix tests/xjnu --ignore-scripts
npm test --prefix tests/xjnu
```

覆盖隐藏详细课程块、重复格子、三节连堂、不连续节次、单双周、不同星期列顺序、缺少教室、教学周历、取消操作、保存失败和登录失效。模拟导入流程还验证只向学校同源发送请求，且不调用作息表或配置的保存接口。

## 在拾光中测试

1. 在“更多”页开启开发者功能。不同版本按钮位置可能略有变化，2.x 通常为点击图标五次。
2. “我的 → 更多 → 更新教务适配仓库”，选择自定义仓库。
3. 仓库填写 `https://github.com/CkYtxwz/shiguang_warehouse.git`，分支填写 `test/xjnu`。
4. 更新后，进入“教务系统导入 → 通用工具 → 适配代码测试”。
5. 输入 `https://jwxt.xjnu.edu.cn/jsxsd/`，在学校页面内登录，进入学生首页后点击“执行导入”。
6. 选择学期并核对导入预览；建议先导入到单独的新课表。
7. 核对课程、单双周、连堂节次、教室，以及目标课表使用的作息时间。
8. 根据完成提示核对第一周开始日期和总周数。脚本只显示学校教学周历，不覆盖现有配置。

`test/xjnu` 是本 Fork 专用的手机测试分支，额外包含 `resources/GLOBAL_TOOLS/test.js`。该文件是正式脚本的相同副本，用于现有测试入口，不需要重新发布学校索引。

正式提交上游时使用 `feat/xjnu` 分支；不要把测试分支的 `test.js` 提交到上游 PR。

## 支持范围和边界

- 新疆师范大学本科教务系统的个人“学期理论课表”。
- 用户自行登录，使用同源 Cookie；脚本不接收或存储账号密码。
- 按真实节次和周次导入，保留目标课表已有的每节起止时间和默认课时长度。
- 暂无排课时间的记录会提示，不会编造星期或节次。部分课程可能同时有已排课和未排课记录。
- 未覆盖研究生系统、教室课表、WebVPN 或其他域名入口。
- 已完成桌面解析和模拟桥接测试；手机 WebView/拾光实际导入仍需实机验收。
